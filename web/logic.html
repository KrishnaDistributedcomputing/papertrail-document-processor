Local AI decision path

How extracted text becomes grounded analysis.

The language model never reads the PDF directly. Papertrail extracts and labels page text first, creates one bounded factual prompt, and sends the same evidence to each selected local Qwen model before storing comparable structured responses.

Input boundary

The model receives text, not the source document

Included in the prompt
  • Original display filename
  • Existing deterministic classification category
  • Extracted page text in page-number order
  • Explicit markers such as [Page 3]
Not sent to the model
  • Raw PDF bytes or embedded files
  • Page images and OCR renderings
  • Text coordinates, font details, or checksums
  • Prior run history or other users' documents

Execution sequence

Seven controlled transformations

  1. 01 Read extraction output

    The worker starts only after PyMuPDF or Tesseract has produced text for each page. Blank page text is omitted.

    result.pages[].text
  2. 02 Preserve page provenance

    Non-empty text is joined in document order with a page marker, so the model can distinguish content boundaries.

    [Page n]\n{text}
  3. 03 Apply the context ceiling

    The assembled string is cut to the configured character limit. The default is 12,000 characters per document.

    AI_MAX_CHARACTERS
  4. 04 Build a grounded instruction

    The prompt says to use only supplied text, avoid missing-fact inference, and return empty arrays when evidence is absent.

    filename + category + text
  5. 05 Generate locally

    The worker calls each selected model sequentially with identical text, temperature 0.1, streaming disabled, and the same output schema.

    1-2 model calls
  6. 06 Parse and normalize

    Papertrail parses the response as JSON, trims strings, rejects malformed entities, enforces list limits, and scores input evidence.

    normalize + confidence
  7. 07 Persist with provenance

    Every model result, metric, status, and warning is written into the versioned JSON result and durable SQLite record.

    analysis + analyses[]

Trust boundaries

What this logic does and does not guarantee

The model is an interpretation layer over already extracted evidence. Classification remains deterministic, and the original text stays available beside every generated insight.
